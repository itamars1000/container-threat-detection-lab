## מה למדנו
- פתיחת קובץ עשויה להיות פעולה מורשית; סמיכות של אירועים מצריכה בדיקת קשר והקשר.
- כתובת מקור, יעד וזהות תהליך הם פרטים שונים. IP לבדו אינו מוכיח עוינות.
- יעד פרטי או מקומי יכול להיות בלתי צפוי לפי המדיניות.
- image נשמר גם אחרי שקונטיינר זמני עם --rm הוסר.
- run יוצר קונטיינר חדש; exec מפעיל פעולה בקונטיינר קיים.
- HTTP 200 ולוג אפליקציה אינם מאשרים שכלל החיישן אסף את האירוע.
- תיקנו כלל רשת לפי שדות client/server שנצפו באירועים אמיתיים.
- פתיחה לקריאה אינה מוכיחה קריאת תוכן; connect אינו מוכיח העברת הקובץ.
- מוני האיסוף מתארים זרימה רחבה יותר ממספר התאמות הכללים.

## מגבלות והמשך
המתאם מנתח הקלטות סגורות ואינו חוסם פעולות. חלון הזמן והחריג יוצרים מגבלות כיסוי מתועדות.

המשך הלמידה: להריץ python3 scripts/demo.py, לקרוא דוח חשוד ודוח תחזוקה ולהסביר את ההחלטה והגבולות.
